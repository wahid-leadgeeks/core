# CORE

## Company Operations, Resources & Environment

Internal administrative platform for managing company-owned resources, infrastructure, accounts, access, hardware, and software.

---

## Problem

Company infrastructure data is currently distributed across multiple spreadsheets.

Examples:

- User accounts
- Google Groups
- Company laptops
- Device access
- Software
- Applications
- Licenses
- Subscriptions

This creates problems:

- Duplicate data
- Difficult searching
- No relationship visibility
- Manual updates
- Limited history
- Weak access control
- Spreadsheet dependency
- Difficult auditing

---

## Goal

Create one secure internal platform where authorized administrators can manage company resources.

CORE should answer:

- What accounts does the company own?
- Who is assigned to each account?
- What Google Groups exist?
- Who belongs to each group?
- What laptops does the company own?
- Who currently has each device?
- What software does the company use?
- How many licenses are available?
- Who has access to sensitive resources?
- What changed and who changed it?

---

## Users

### Super Admin

Full system access.

### IT Admin

Accounts, Google Workspace, devices, software.

### Asset Admin

Hardware and asset assignments.

### Software Admin

Applications, licenses, subscriptions.

### Auditor

Read-only access to approved resources and audit logs.

---

## Core Modules

1. Identity
2. Google Workspace
3. Assets
4. Software
5. Access
6. Automation
7. Audit

---

## Success Criteria

CORE successfully replaces spreadsheets as the primary interface for managing company resources.

Administrators can:

- Find resources quickly
- Track assignments
- View history
- Manage relationships
- Detect conflicts
- Control access
- Audit changes
