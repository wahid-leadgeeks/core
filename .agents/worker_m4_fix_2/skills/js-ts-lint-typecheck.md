# JavaScript & TypeScript Quality Gate: Lint & Typecheck

Standardized workflow for detecting, executing, and resolving typechecking and linting checks across JavaScript and TypeScript codebases.

## Quick Command Reference
- Typecheck: `npm run typecheck` or `npx tsc --noEmit --pretty false`
- Lint: `npm run lint` or `npx eslint .`
- Build: `npm run build`
